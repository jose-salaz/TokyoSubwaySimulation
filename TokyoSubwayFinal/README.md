# TokyoSubwayFinal

This project simulates a single-station Tokyo subway system for the CS 4632 final deliverable. It models passenger arrivals, train operations, and logs metrics like wait times, queue lengths, and rejections.

## Project Structure
- `src/main/java/TokyoSubway/`: Main classes (`SubwaySimulation`, `PassengerGenerator`, `Train`, `DataLogger`).
- `src/test/java/TokyoSubway/`: Test classes (`PassengerGeneratorTest`, `SubwaySimulationTest`).

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run `SubwaySimulation.main()` to execute the simulation.
   3. Run the tests (`PassengerGeneratorTest` and `SubwaySimulationTest`) to verify the implementation.
